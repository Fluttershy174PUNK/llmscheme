# 🗺️ llmscheme

**Живая схема твоего проекта** — модули, потоки данных и экраны в одном JSON,
который обновляется при каждом изменении кода. Читается одинаково человеком,
AI-агентом и визуальным редактором.

---

## 🤔 Зачем это?

Код растёт, а карта проекта живёт в голове или в устаревшей вики. llmscheme
хранит карту **рядом с кодом** и перегенерирует её при каждом сохранении.

| Было | Стало |
|---|---|
| 🤷 «Как это устроено?» → grep + угадывание | ✅ открыл схему — видно модули и потоки |
| 📝 Рукописные доки, устаревшие вчера | ✅ `SCHEME.md` генерится из схемы |
| 🧩 Несколько источников правды | ✅ один `scheme.json` — источник истины |

## 🚀 Установка скилла (для AI-агента)

Скилл уже собран и готов. Скопируй папку в скиллы агента — и всё.

```bash
git clone <url-репозитория> llmscheme
cp -r llmscheme/SKILL/llmscheme ~/.claude/skills/llmscheme
```

| Агент | Папка скиллов |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Cursor | `.cursor/skills/` |

Готово. Агент получил команду `block`. Работает **офлайн**, без `npm install`,
без сети и без API-ключа. Нужен только Node ≥ 22.18.

## 🧠 Как работает скилл

Агент ведёт схему простыми командами:

```bash
node <skill-dir>/cli/block.ts init --type logic            # создать схему
node <skill-dir>/cli/block.ts node add --label "Login"     # добавить модуль
node <skill-dir>/cli/block.ts edge add --from n1 --to n2   # связать модули
node <skill-dir>/cli/block.ts validate                     # проверить
```

Три независимые схемы на проект: `logic` (модули + потоки), `code` (граф
вызовов), `ui` (экраны). Из `scheme.json` при каждом сохранении генерируются
`SCHEME.md` (читаемая сводка) и `scheme.html` (редактор двойным кликом).

## 🖥️ Установка сервиса (веб-консоль + MCP для команды)

```bash
cd SERVICE-MCP/llmscheme
cp .env.example .env          # задай ADMIN_PASSWORD
docker compose up -d
```

Консоль: `http://localhost:8080/` (логин `admin` / твой пароль).

## 🔌 Как работает сервис

Один процесс отдаёт четыре вещи:

| Что | Где | Для кого |
|---|---|---|
| 🖥 Веб-консоль | `/` | проекты, юзеры, API-ключи |
| ✏️ Редактор | `/editor/<схема>` | править схему в браузере |
| 📡 REST API | `/api/...` | скрипты и автоматизация |
| 🤖 MCP | `/mcp` | инструменты для AI-клиентов |
