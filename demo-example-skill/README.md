# 🐱 Cat Gallery Generator (demo)

> Demo-проект для скилла block-llm: наглядная схема «генератора котиков»,
> собранная самим CLI скилла (dogfooding).

## ⚙️ Что делает pipeline

```text
cats.txt ──> Load cats ──> Make cat ──> Score cats ──┬─> Pick top cat (победитель :purr:)
 ("url|имя")                                         └─> Build gallery ──> Write cats.html
```

1. **Load cats** — читает `cats.txt`, одна строка = один котик в формате
   `url|Имя` (или `путь/к/файлу|Имя` для локальных картинок).
2. **Make cat** — превращает строку в объект `Cat` (url или файл).
3. **Score cats** — наивный рейтинг 0..100 + настроение
   (happy 😺 при >40, иначе sleepy 😴).
4. **Pick top cat** — победитель списка.
5. **Build gallery** — самодостаточная HTML-страница в пиксельном стиле:
   каждая карточка = картинка + штамп настроения + оценка `/100`.
6. **Write cats.html** — пишет файл на диск.

## 🚀 Запуск

```bash
node --experimental-strip-types src/main.ts cats.txt cats.html -v
# → Cats (best: Mursik :purr:): 4 cats -> cats.html moods: {"happy":3,"grumpy":0,"sleepy":1}
```

Открой `cats.html` в браузере — готовая пиксельная галерея.
Добавь своих котиков в `cats.txt` (url или локальный файл) и перезапусти.

## ✅ Что проверить в схеме

1. 🖼 Открой `.block_llm/scheme.html` двойным кликом — редактор схемы:
   - #️⃣ сетка (полупрозрачная) и ⊕ магнит к ней — кнопки в топбаре;
   - 🎨 палитра фигур справа: клик по фигуре → клик по канвасу = новый узел;
   - 📊 узел `Cat catalog` (table-элемент, до 10 колонок × 50 строк) — кликни
     на него: в инспекторе справа интерактивный редактор таблицы с кнопками
     `+`/`−` для строк и колонок;
   - ↩️ узел `Dedup module` — многострочный label (Enter в поле label
     переносит строку, узел растягивается вниз).
2. 📄 `SCHEME.md` — mermaid-диаграмма и таблицы (видно на GitHub).
3. 🔁 Главный цикл скилла: правишь схему в редакторе → SAVE (tier A копирует
   блок команд) → агент применяет через CLI → код обновлён. Живые примеры:
   `src/dedup.ts` и `src/index.ts` созданы агентом по узлам `n12`/`n14` схемы.

Не является частью раздаточного скилла: в `~/.agents/skills` не копируется.
